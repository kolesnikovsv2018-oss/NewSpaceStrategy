## Как выполнять и публиковать

- «Независимо» означает: после принятых предпосылок результат полностью работает, проверяется и может быть опубликован **без следующих этапов**. Это не независимость от уже реализованных предыдущих этапов.
- Не публиковать половину схемы с неработающим UI или заглушкой AI под видом готового игрового этапа. Контрактные Н01/Н04 и инструментальный Н03 имеют явно ограниченный результат.
- Новые правила заменяют актуальную версию единой кампании, а не добавляют параллельный основной режим. Н05 уже подключил общий генератор при старте; Н05а/Н06–Н19 расширяют этот путь. На каждом промежуточном этапе остаются действующие правила для ещё не заменённых систем.
- Чтение/импорт и запись используют только актуальную новую версию данных. Каждый этап, меняющий формат, обновляет его producers/consumers и fixtures; иная версия отклоняется явно, без преобразований и резервной загрузки.
- Если этап слишком велик для одной сессии, сначала предложить вертикальные подзадачи: каждая имеет собственные схемы, команды, UI/AI/save и проверки либо является честно самостоятельным инструментом/контрактом. Не менять зависимости без обновления этого указателя и основного плана.
- Каждый этап включает обновление документации, навыков и новый отчёт. Коммит/push — только по отдельному прямому запросу; «может быть запушен» не является поручением выполнить push сейчас.

## Генератор галактики

Отдельный [план-промпт генератора](../galaxy-generator-prompt-2026-10-09.md) содержит этапы Г01–Г04: автономный формат/валидация, детерминированная генерация, CLI с обязательной записью JSON и подключение к кампании.

Подтверждённые требования: достижимость проверяется **для каждого участника из его собственного стартового мира**; сохранение — **отдельным JSON-файлом на диске через CLI**, не только localStorage или скачивание из браузера.

Г01–Г03 реализованы автономно. Н05/Г04 выполнены для двух участников; [отчёт](../../reports/2026-10-09/05-browser-galaxy-integration.md). Н01/Н04 не блокировали эту поставку и позднее приняты самостоятельно. Метрическую политику маршрутов вводит Н14, больше двух участников в игре — Н17. Н06 требует также принятого Н04: каталог вместимостей и демография не входят в интеграцию генератора.
