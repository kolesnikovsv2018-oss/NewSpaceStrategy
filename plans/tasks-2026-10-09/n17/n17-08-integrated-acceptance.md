# Н17.8 — сводная приёмка Н17

**Этап:** Н17.8 (подэтап [Н17](../n17-multiple-factions.md)). **Предпосылки:** Н17.7 и транзитивно Н17.1–Н17.6. **Статус:** задание, не реализация.  
Выполняй с [общим контрактом](../00-execution-contract.md), [основным планом](../../plan-2026-10-09.md) и родительским заданием [Н17](../n17-multiple-factions.md).

## Промпт и завершённый результат

Прими Н17 целиком по матрице родительского задания на актуальном коде: пройди каждый пункт
приёмки [Н17](../n17-multiple-factions.md), включая браузерную приёмку UI (в том числе
отложенный в Н16 долг по вкладке «Дипломатия»), обнови документацию, навыки и статусы.
Это приёмка, а не новая функциональность.

## Работы

1. Проверь результат Н17.7 по отчёту и git status; подтверди статус [Н17](../task-status.md)
   «В процессе».
2. Пройди матрицу родителя построчно; каждая строка — проверка, фактический результат,
   тест/файл. Минимум:
   - P=2 сохраняет принятую двухстороннюю механику; P=3 и max — ровно одно начисление
     каждому за цикл;
   - elimination/skip/последняя сторона/переход round и истечение договора; ни один load
     не запускает scheduler;
   - человек не командует чужим AI; observers не меняют active/control;
   - каждый участник видит только свои проекты и доступное оборудование; редактор/заказ
     не используют чужой каталог; save/load сохраняет все каталоги без смешивания;
   - три стороны в системе: разные treaty графы, уничтожение/timeout, корректные
     losses/operations/groups, один легальный capture;
   - перестановки массивов и зеркальные старты: стабильность policy/streams в оговорённых
     границах;
   - save/load на каждом участнике/в пути/перед встречей равен следующему oracle;
   - генерация/start/save/load P=2/3/max: отдельные дома и две ближайшие цели **каждого**
     участника; ошибка записи/отмена не заменяют партию; load не читает latest-map
     и не генерирует.
3. Настоящий браузер 1280×720 и 390×844: pointer/keyboard, длинные имена, ошибки,
   save/reload/load, cancel/reentry; local + несколько AI; вкладка «Дипломатия» по образцу
   Н15 (долг Н16). Заглушки Phaser не считать браузерными.
4. Документация согласована с фактом: CAMPAIGN_MULTI_FACTION, CAMPAIGN_CONQUEST,
   CAMPAIGN_DIPLOMACY, CAMPAIGN_CONTROL, CAMPAIGN_UI, GALAXY_GENERATOR, CAMPAIGN_SAVE;
   навыки актуализированы по orion-skill-maintenance.
5. Полный `yarn test`, `typecheck`, `build`; фикстуры/примеры соответствуют актуальной
   единственной версии формата.
6. Отчёт по навыку orion-task-report в reports по фактической дате, новым номером; обнови
   строку [Н17](../task-status.md): при выполненных критериях «Выполнено», иначе
   «В процессе» с причиной; укажи следующий допустимый этап (Н18 требует Н17 целиком).

## Приёмка и проверки

- Каждый пункт родительской матрицы проверен на актуальном коде новым прогоном; исторические
  проверки не выдаются за новые.
- Браузерная приёмка actual Chromium на обоих профилях; 0 pageerrors / 0 console-ошибок
  фиксируется в отчёте.
- Н-граф не меняется; ограничения и следующий этап записаны в журнале.

## Не входит и независимая поставка

Новые функции и политики; исправления вне найденных при приёмке дефектов; Н18-механики.
