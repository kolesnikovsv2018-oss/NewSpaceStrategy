# Н17.4 — дипломатия на пары участников

**Этап:** Н17.4 (подэтап [Н17](../n17-multiple-factions.md)). **Предпосылки:** Н17.2, Н17.3. **Статус:** задание, не реализация.  
Выполняй с [общим контрактом](../00-execution-contract.md) и [основным планом](../../plan-2026-10-09.md).

## Промпт и завершённый результат

Переведи дипломатию Н16 с однопарной модели на per-pair отношения участников: контакт,
доверие/репутация/влияние, предложения с явным получателем, договоры и вето на каждую пару.
Раунд дипломатии — полный круг расписания с единой точкой истечения; treaty gate во встречах
действует по парам. Правила и цены Н16 сохраняются как принятые.

Опоры: [campaignDiplomacy](../../../src/domain/campaignDiplomacy.ts), интеграция в
[conquest](../../../src/domain/conquest.ts), [conquestAi](../../../src/domain/conquestAi.ts),
[ConquestScene](../../../src/scenes/ConquestScene.ts),
[документ Н16](../../../docs/CAMPAIGN_DIPLOMACY.md),
[контракт Н17.1](../../../docs/CAMPAIGN_MULTI_FACTION.md).

## Работы

1. Проверь результаты Н17.2/Н17.3 по коду/отчётам и git status; подтверди статус
   [Н17](../task-status.md) «В процессе».
2. Схема: отношения по неупорядоченной паре участников (канонический ключ пары); per-side
   счётчики Н16 (репутация/влияние/вето) сохраняются; лимиты пересчитаны для P≤8 — pending
   на сторону на пару либо глобально, пределы предложений/договоров/журнала по решению Н17.1.
3. Команды: `proposeDiplomacy` с явным recipient (`player-NN`); гейты контакта/войны
   per pair; обмен атомарен per pair с pre-check вместимости казны получателя; авторизация
   автора/получателя по парам; предложение раскрывает получателю отправителя.
4. Раунд: `advanceDiplomacyRound` после endTurn последнего участника круга (расписание
   Н17.2) вместо `expectedTurn % 2 === 0`; сроки не застревают на исключённых участниках;
   coop round-guard per pair; единая точка истечения сохранена.
5. Treaty gate в `settleEncounters` по паре конкретного боя/захвата: перемирие с A не
   блокирует бой/захват против B; захват при coexistence/timeout выполняется только при
   соблюдении всех условий своей пары, не просто «в системе >1».
6. AI: реакции на предложения по парам (score per pair), инициативы в хвосте приоритетов
   без утечек; бюджет команд прежний; перемирие AI сам не инициирует — правило Н16
   сохранено на каждую пару.
7. UI: вкладка «Дипломатия» с выбором адресата, свои предложения/договоры по парам, журнал
   без скрытого state; own-view не раскрывает чужие казны/исследования/планы.
8. Save: per-pair блок в снимке, round-trip; фикстуры обновлены; изменение формата
   diplomacy отражено в версиях из Н17.1.

## Приёмка и проверки

- P=2: принятое в Н16 поведение сохранено — коды, сроки, цены, атомарность обмена,
  round-guard.
- Пары независимы: война с A не мешает coop с B; гейт точечный; три участника — разные
  treaty графы в одной системе.
- Double accept/stale/отозванное/expired per pair; один обмен списывает/начисляет ровно
  раз; round expiry не срабатывает дважды за круг.
- Модульные тесты с тремя участниками; regression Н16 (campaignDiplomacy 28) адаптирован
  и зелёный.
- tests/typecheck/build.
