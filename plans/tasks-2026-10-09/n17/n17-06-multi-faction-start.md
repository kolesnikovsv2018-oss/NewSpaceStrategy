# Н17.6 — старт многосторонней кампании P=2..max end-to-end

**Этап:** Н17.6 (подэтап [Н17](../n17-multiple-factions.md)). **Предпосылки:** Н17.2, Н17.3, Н17.4, Н17.5. **Статус:** задание, не реализация.  
Выполняй с [общим контрактом](../00-execution-contract.md) и [основным планом](../../plan-2026-10-09.md).

## Промпт и завершённый результат

Разблокируй утверждённый диапазон P на всей вертикали: браузерный выбор участников,
синхронный предел миров, elimination/skip/observer, цвета/имена по metadata, генерация/
start/save/load для P=2/3/max без маппинга «первый blue, остальные red». CLI/browser/
codec/checker сохраняют один актуальный формат и метрический профиль Н14; новый импорт
карт в UI не требуется.

Опоры: [BrowserGalaxyGenerator](../../../src/utils/BrowserGalaxyGenerator.ts), диалог
новой кампании в [ConquestScene](../../../src/scenes/ConquestScene.ts),
[galaxyGenerator](../../../src/domain/galaxyGenerator.ts),
[galaxyMap](../../../src/domain/galaxyMap.ts),
[galaxyCli](../../../src/cli/generateGalaxy.ts), [conquest](../../../src/domain/conquest.ts),
[ConquestSaveManager](../../../src/utils/ConquestSaveManager.ts).

## Работы

1. Проверь результаты Н17.2–Н17.5 по коду/отчётам и git status; подтверди статус
   [Н17](../task-status.md) «В процессе».
2. Доменная граница: схема кампании принимает участников утверждённого диапазона из Н17.1;
   P вне диапазона отклоняется явно; предел миров ≥ 3×P enforced на границе кампании.
3. Браузер: кнопка «Участники» 2..max активна; нижний предел миров = max(6, 3×P); seed один
   раз на IO-границе; карта и кандидат кампании полностью проверены до записи; ошибка
   записи/отмена не заменяют прежнюю партию.
4. Elimination/skip end-to-end: ноль колоний не устраняет сторону с кораблями; исключённые
   пропускаются расписанием; полный круг и сроки договоров не застревают; победа по прежнему
   all-planets-v1.
5. UI: цвета/имена по metadata участников; выбор наблюдателя/следующей local стороны;
   собственные каталоги/редактор per participant (владельцы/ID/доступность/own-view/save);
   standings/сообщения без скрытой казны.
6. Save/load: полный снимок на P=2/3/max; load не читает latest-map и не генерирует;
   multi-AI последовательность end-to-end (человек + несколько AI, один пакет на активного
   AI).
7. CLI/codec/checker: один формат карты и кампании; примеры/фикстуры для P=3/max;
   генерация CLI уже поддерживает 2..8 — согласуй границу кампании и документацию.
8. Регрессии: отдельные дома и две ближайшие доступные цели **каждого** участника при
   P=2/3/max; три стороны в системе end-to-end; elimination/skip/переход round/истечение
   договоров end-to-end.

## Приёмка и проверки

- Генерация/start/save/load для P=2/3/max сохраняют отдельные дома и две ближайшие
  доступные цели каждого участника; не только человеческой стороны.
- Три стороны в одной системе: разные treaty графы, уничтожение/timeout, корректные
  losses/operations/groups и один легальный capture.
- Человек не командует чужим AI; observers не меняют active/control; ни один load не
  запускает scheduler/AI.
- Устранение стороны, последний участник, переходы раундов и истечение договоров корректны.
- Полный `yarn test`, `typecheck`, `build`; настоящий браузер desktop/mobile: новая кампания
  P=3, ход нескольких AI, save/reload/load, отмена/ошибка записи.

## Не входит и независимая поставка

Новые победы (Н18); сетевой мультиплеер; безусловные альянсные флоты; новый импорт карт
в UI. Полная многосторонняя кампания использует предыдущее условие военной победы
и принятые встречи, не ждёт Н18.
