# Управление кампанией и обучение — Н02

Дата: 2026-10-10. Руководство описывает работающий Conquest, не будущую научную экономику или кампанийный редактор.

## Первый оплаченный маршрут

1. В меню выберите **Новая кампания**. Настройте 6–256 миров и локальное управление либо компьютер. Участников сейчас ровно два. Новая партия появляется только после успешной записи карты; отмена не генерирует карту.
2. **Исследования / Наука**: начните support за 10 кредитов. Цена списывается один раз; два собственных конца хода завершают исследование. Без колоний прогресс приостановлен. Следующие открытия требуют предыдущих.
3. Откройте **Проекты кораблей**: создайте черновик, выберите доступный корпус и оборудование, сохраните проект своей стороны. Затем выберите свою колонию, откройте **Производство / Заказы** и закажите его. Каталог использует проекты текущей партии и доступные пресеты, не общую библиотеку. Сохранение чертежа не оплачивает заказ и не создаёт корабль; [контракт Н05а](CAMPAIGN_PROJECTS.md).
4. Выберите доступный проект и оплатите **Заказать**. Цена и срок показаны до оплаты. Только первый заказ каждой своей колонии продвигается на её конец хода. Отмена возвращает долю цены за оставшийся срок.
5. Готовую запись нужно отдельно **Разместить**. Размещение не меняет ход и не списывает вторую цену. Чертёж и готовый заказ ещё не являются размещённым кораблём.
6. **Корабли и группы / Корабли**: отметьте корабль, затем соседнюю цель. Отправка тратит 1 топлива, прибытие происходит на собственный конец хода. Бак 3; заправка в своей колонии — 5 кредитов / 2 минерала за единицу. Группа тратит топливо каждого участника.
7. При встрече бой рассчитывается внутри команды конца хода. Отчёт и воспроизведение — только просмотр уже принятого результата.

В локальном режиме после своего конца хода переключите наблюдение на другую сторону для её действий. На телефоне переключение находится во вкладке **Партия**. В AI-режиме наблюдение всегда синее; после загрузки красного хода компьютер остаётся **paused**, пока явно не подтверждён **Продолжить AI**.

## Разведка, службы и победа

- Наблюдение дают своя колония, стоящий корабль и сканер. Без присутствия прежнее наблюдение снова скрывается; неизвестный мир не раскрывает владельца или пригодность.
- Гражданский корабль может явно колонизировать наблюдаемую свободную пригодную планету без врагов. Вооружённый корабль занимает её автоматически на конец хода.
- Захват требует вооружённого присутствия и отсутствия живых защитников. Незавершённый бой сам по себе не даёт захвата.
- Ремонт и снаряды оплачиваются отдельно. UI показывает кредиты / минералы для выбранного корабля; в поле ремонт требует repair-модулей, заправка и снаряды требуют своей колонии.
- Победа — все пригодные миры снимка карты, не только столица. После победы игровые действия запрещены; просмотр, справка, save/load и новая партия доступны.
- Стратегический ход — окно действий одной стороны. Боевой такт — 0,05 секунды симуляции, лимит боя 120 секунд. Время просмотра/replay не начисляет доход, исследование или производство.

Полные тарифы и правила: [контракт Conquest](CAMPAIGN_CONQUEST.md).

## Компоновка и согласованные пороги

Пользователь подтвердил основной текст **не менее 14 CSS px**, кнопки **не менее 44×44 CSS px** на контрольных экранах **1280×720** и **390×844**.

| Экран | Логический canvas и CSS-прямоугольник | Масштаб | Основной текст | Минимальная кнопка |
| --- | --- | --- | --- | --- |
| Desktop 1280×720 | 1280×720, начало (0, 0) | 1 | 14 CSS px | 44×44 CSS px |
| Mobile 390×844 | 390×844, начало (0, 0) | 1 | 14 CSS px | 44×44 CSS px |

Размеры проверяются по `canvas.getBoundingClientRect()`, не по размеру screenshot-preview или DPR. При переключении этих размеров масштаб также остаётся 1. Проверки относятся к указанным контрольным viewport, не являются гарантией всех меньших размеров или landscape.

- Desktop сохраняет обзорную мини-карту и четыре рабочие вкладки. Для плотной сгенерированной карты основной способ выбора — **Выбрать мир**, а не мелкие точки.
- Mobile имеет отдельные вкладки **Мир / Наука / Заказы / Корабли / Бои / Партия**. Данные списков показаны по одной записи; выбор мира использует страницы по восемь записей. Доступны последний из 256 миров и все четыре соседние цели.
- Текст и hit areas используют одинаковые размеры виджетов. Имена обрезаются по измеренной ширине текста; исходные проекты и state не меняются. Сообщение доменного отказа переносится целиком в нижней области текущего экрана.
- Кнопки исследования/заказа в разрешённое окно действий позволяют получить настоящий отказ домена, например нехватку ресурсов или предпосылок. UI не списывает ресурсы заранее.
- Справка — пять страниц текущих правил, без собственных настроек, сохранения или IO. Она приостанавливает ожидающий AI, но не выполняет его ход.
- ESC закрывает справку/выбор/подтверждение без дополнительного выхода. Событие ESC, уже перехваченное host-shell, передаётся активному Phaser keyboard ровно один раз. После закрытия следующая отдельная ESC может запросить меню.
- Изменение viewport отменяет открытый диалог с явным сообщением; партию не заменяет. Shutdown снимает native/Phaser handlers и возвращает канонический canvas 1280×720 для прежних демонстраций.

Мирная песочница и испытания сохранены в **Демонстрациях**; их прежний фиксированный UI и readers не переписаны. Н02 адаптирует меню и основную военную кампанию, не объявляет старые демонстрации новым mobile-UI.
