# Стратегические перелёты: контракт Н14 и история Д08

## Н14: согласованный контракт

Согласован и принят2026-10-25: [приёмка19](../reports/2026-10-25/19-n14-strategic-travel.md).
Прямые евклидовы расстояния0..1000 без линий сохраняются.
Отдельный обязательный strategicEquipment проекта содержит policy
project-travel-v1 и независимые drive/jump/tank. Базовый комплект входит
в корпус, новых слотов нет; tactical speed/тяга/энергия не используются.

Доплаты складываются в канонической цене; mass/volume/tactical ratings/
minerals неизменны. Каждая опция меняет ровно свою величину. Research
открывает только выбор: существующие проекты/заказы/ships не обновляются.
Новый экземпляр оплачивается производством, прежний — refit.
Scanner сохраняет отдельный радиус исследований стороны200/400/800/1500.

Distance=Math.hypot исходных координат без округления/epsilon.
Turns=max(1,ceil(distance/speed)); расход=ceil(distance×5) тысячных.
Exact jump/fuel разрешены; неверные/неfinite/overflow явно отвергаются.
Расход списывается единожды при send. Полная refuel только в своей
колонии:ceil(missing×5/1000) credits и ceil(missing×2/1000) minerals.

В пути нет присутствия/visibility/services/mining/battle у endpoints.
Успешный own-end уменьшает remaining; enemy-end не двигает маршрут.
На последнем шаге arrival происходит до mining/encounters по прежнему
pipeline. Прогноз mining учитывает только stationary/arriving этим own-end.
Транзакционные S0/upkeep/FIFO/rollback прежние.

Fleet летит по минимальным speed/jump, синхронно; у каждого свой fuel,
все quotes проверяются до списаний. Route/capability snapshot хранится
в ship.transit, не на fleet/в UI; новая наука/catalog не меняют его.
Load midway автономен от latest-map, не генерирует карту.

Refit сохраняет абсолютные HP/fuel; новый бак не заправляется.
Уменьшение ниже текущего fuel отвергается. Ammo-контракт Н13 прежний.
Без redirect/cancel в пути, автоконвоев и auto-refit AI.
Мирный gameplay и тактика Н13 прежние; только current readers.

## История Д08

Согласованная подготовка Н10,2026-10-25. Это не полный Н14:
разные стратегические двигатели/баки проектов, скорость и дистанционные

## Дальность

В новой карте нет линий. Любая пара разных миров является потенциальной
целью прямого перелёта. Общие `getWorldDistance`/`isWorldInRange` считают
евклидово расстояние по исходным координатам0..1000 в галактических единицах,
не экранных pixels или тактической скорости. Точный порог разрешён.

Начальная дальность200, engineering открывает400, ordnance800,
capital1500. Дерево5 хранит эффекты `strategic-range`, rules snapshot6 —
начальную policy. Применяется максимум, не сумма. Три открытия обязательны
и достижимы в актуальном импортируемом дереве. Последний уровень покрывает
диагональ карты. Новое исследование не меняет уже отправленный корабль.

Бак3, расход1/прямой перелёт, arrival за один свой endTurn.
Заправка только в своей колонии:5 credits/2 minerals за единицу.
Группа проверяет каждый бак до любого списания.
Низкоуровневый Conquest session-вход требует явную дальность отправки;
полная игровая граница вычисляет её из проверенного собственного исследования.
Мирная песочница сохраняет свои линии и API.

Scanner с положительными range/accuracy наблюдает миры в пределах текущей
стратегической дальности стороны. Номинальная тактическая дальность модуля
не становится галактическим расстоянием. Без scanner корабль видит только
свою систему. Историческое знание пригодности до Н10 следует из собственной
разведки, не из чужого владения; актуальные враги/owner требуют наблюдения.

## Колонизатор

Отдельный hull `colonizer`: масса130, maxMass350, HP500, cost8000,
energy2000, scale1, трюм100/100, восемь стандартных слотов.
Готовый безоружный проект с обычным двигателем имеет массу182,
цену229 credits/19 minerals и productionCost23.
Flight/battle валидируются отдельно, отсутствие оружия не является
разрешением обходить боевой валидатор.

Корпус и проект открыты изначально. Дома сторон получают по одному
бесплатному кораблю: глобальные ship IDs1/2, production.lastOrderId2,
полные HP/fuel3. Последующие экземпляры оплачиваются обычным FIFO.
Новый hull доступен в общем редакторе; прежний мирный production-каталог
из семи пресетов не меняет порядок библиотечных записей.

`colonize` требует явный shipId стоящего своего колонизатора в цели.
Успех расходует корабль/operations, корректно убирает membership
и расформировывает группы менее двух кораблей; ID не возвращается.
Переименование другого корпуса не даёт способности.
Источник — ближайшая по прямому расстоянию своя колония с P≥2000,
при равенстве ASCII ID. Перенос1000 и цена20/10 сохранены.
При отказе весь state неизменен.

Вооружённого автооснования больше нет. Военный захват населённого
чужого мира отдельный: без колонизатора и платы, с сохранением жителей.
Н10 дополнил основание [survey и адаптацией](CAMPAIGN_PLANETOLOGY.md),
не меняя стратегическую метрику или расходование колонизатора.
