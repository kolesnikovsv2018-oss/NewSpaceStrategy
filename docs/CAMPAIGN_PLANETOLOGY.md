# Н10 — среда, изучение и адаптация

Согласованные правила от2026-10-25; продолжение
[Д08: прямые перелёты/колонизатор](CAMPAIGN_TRAVEL.md).
Терраформирования, смены типа командой и новых условий победы нет.

## Источники истины

- `session.galaxy.map` — неизменный canonical map3, исходные координаты,
  типы, дома и состав военных целей.
- `Conquest.environment` — ровно один текущий тип на каждый world ID.
  Инициализируется из проверенного snapshot, отдельно сохраняется.
  Для фиксированного Conquest-сценария начальные типы заданы его определением.
- `Conquest.surveys.blue/red` — собственные изученные сведения
  `{worldId: observedType}`. Не полный runtime противника и не availability.
  Дома изучены с начала; захваченная колония передаёт свои данные.
- `getEnvironmentType`/`getColonyWorldType` дают тип доверенным consumers.
  Conquest явно передаёт runtime в growth/output/capacity/mining.
  Мирные typed helpers сохраняют расчёты по исходному определению;
  отсутствие environment в военном save не вызывает такой fallback.

Полная схема проверяет точные world IDs, population/assignments текущих
колонизируемых сред и отсутствие ownership в barren.
Наличие адаптации не является invariant ownership: оккупация разрешена.
Текущую среду не прогоняют через checker исходного генераторного профиля.

## Типы и исследования

| Тип | Основание | Базовый K / absolute |
| --- | --- | --- |
| habitable | После собственного survey | 10000 /20000 |
| toxic | Survey и завершённый colonization-unlock toxic | 6000 /12000 |
| barren | Недоступно в Н10 | 0 /0 |

Корневой `toxic-adaptation` стоит3000 науки. Его открытие не меняет
тип, вместимость, население или уже сделанные назначения.
Дерево6 обязано содержать достижимую адаптацию и уровни дальности Д08.
Импорт не может убрать необходимые возможности, требуя будущие Н11/Н15/Н19.
Цена/прогресс/резерв/журнал и максимум одно открытие за own-end прежние.

Пять заработанных бонусов Н09 применяются к обоим колонизируемым типам
через явные уникальные `worldTypes` selectors. Toxic получает
рост2%→2,4%, biosphere K6000→8000, три выпуска+20%.
Absolute12000, рост/выпуск≤2×base, точность и резервы10×P прежние.
Все колониальные эффекты читают completed S0; открытие внутри endTurn
не увеличивает уже рассчитанные рост/выпуск этого же хода.

## Survey и наблюдение

`survey {factionId,expectedTurn,systemId}` — мгновенная отдельная
стратегическая команда за10 credits/5 minerals, без смены хода.
Нужен свой стоящий корабль в системе либо действующий scanner,
наблюдающий цель в пределах стратегической дальности своей стороны.
Вражеские корабли в цели блокируют изучение.

Проверки state/payload/stale/active/controller/completed прежние;
сначала текущая видимость, затем повтор/враги/ресурсы.
Повтор даёт ALREADY_SURVEYED без второй оплаты.
Отказ атомарен и возвращает явные code/message.

Наблюдение, survey-знание и право основания не взаимозаменяемы.
До survey own-view не раскрывает тип/параметры через старое habitable,
quotes или прогноз добычи. Флаг habitable без знания означает только
«не подтверждена колонизируемая среда», не «это barren».
UI показывает отдельное «среда не изучена».

Вне наблюдения сохраняется последний собственный изученный тип,
но не актуальные owner/враги. В текущем наблюдении уже изученный мир
показывает текущую среду; успешные команды сохраняют обновлённые сведения.
Это не бесплатное первое изучение неизвестного мира.
Query не меняет state. Собственный forecast/AI не читает чужие surveys.

Добыча требует изученного barren и фактической barren-среды.
Неизученная цель не выдаёт секретный тип через income/treasury;
после разрешённого survey добыча действует по прежней формуле.

## Основание и захват

Общий `colonizationAvailability` обслуживает query, UI/AI и manual command:
наблюдение → survey → занятость/среда → враги/колонизатор → unlock →
источник жителей/ресурсы. Неразрешённые сведения не появляются в ранних ошибках.

Основание требует конкретный свой стоящий hull colonizer и явный shipId.
Он расходуется только при успехе, с очисткой operations/membership.
Переносятся1000 жителей из ближайшей Euclidean/ASCII своей колонии с≥2000,
списывается20/10. Вооружённого автооснования нет.

Захват существующей колонии требует вооружённое присутствие без защитников,
но не колонизатор/адаптацию. P/остаток сохраняются; normal management/growth/output
работают по текущей среде, без бесплатных жителей и без unlock других оснований.
Данные о среде захваченной колонии доступны новому владельцу.

## Генерация и военная цель

Профиль `balanced-start-v3`, generator-v3, map schema/rules3.
Дома и две ближайшие начально доступные цели каждого участника habitable;
дальность200 и геометрические гарантии Д08 сохранены. Линий нет.

Для E дополнительных миров:

```text
C = floor(70 * E / 100)
T = E < 2 ? 0 : min(C, max(1, floor(20 * E / 100)))
toxic = T
habitable = C - T
barren = E - C
```

Минимальные6 миров не требуют toxic; контрольный новый цикл работает на8.
CLI2–8 участников и браузер2 используют один генератор/checker/codec.
До Н18 all-planets — исходные habitable+toxic, не текущая среда/unlock.
Даже будущая runtime-пригодность исходного barren не добавляет военную цель.
