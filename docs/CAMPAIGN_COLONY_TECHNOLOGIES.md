## Одна связь и один расчёт

Узел tree4 содержит `colony-effect {effectId}`.
Описание числового modifier существует в rules snapshot5/rules5.
Действующие effect IDs регистрирует поставляемый каталог; импорт дерева
может ссылаться только на поддерживаемые IDs. Неизвестная ссылка — ошибка,
не пустой эффект. Параметры сохранённого snapshot автономны от каталога.
Conquest проверяет связи и допускает только исполнимые колониальные
modifiers, не библиотечные примеры боевых/policy effects.

Scope — `own-colonies`; обязательный worldType — habitable либо barren.
До Н10 текущий тип берётся из начальной карты партии через общий query.
После Н10 источник query заменяется runtime-средой, не меняется snapshot.
Н09 не разрешает колонизацию barren; типовые фильтры проверяются
вычислителем независимо от существования колонии.

Группы, add/multiply и cap используют арифметику Н04:
одна исходная база группы, один расчёт всех modifiers, один итоговый
целочисленный результат.100/+10%/+20% в одной группе даёт130;
два multiply дают132. Один effect ID применяется один раз.
Ledger принадлежит вычислению, не сохраняется как накопленный бонус.

Рост рассчитывается в базисных пунктах:2%=200,2,4%=240.
Точность ставки —0,01 процентного пункта.
Население остаётся целым. Остаток хранит сотые доли прежней единицы
остатка: `0 <= remainder < 100`, точность0,01.
Числитель в целых: `P×rateBps + round(remainder×100)`;
delta — целая часть деления на10000 с ограничением K−P,
новый remainder — остаток деления/100. При достижении K остаток0.
При0/K/>K жители не создаются и не обрезаются.
Таким образом без технологий сохраняется прежняя арифметика2%/остатка.

## Время, журнал и проекция

Все пять эффектов используют completed на начало own endTurn, S0.
Промышленный/научный/культурный выпуск и рост одной транзакции не читают
только что обновлённый completed. Новые жители не работают в этом ходе.
Science-output технология не финансирует себя или следующий узел в T.
Новая технология действует на развитие со следующего own-end.

`researchJournal` хранит для каждой стороны ход открытия каждого completed
узла, не derived K/output или дополнительный completed.
Ключи журнала согласуются с completed; UI получает только свой журнал.
Отложенная активация выводится из хода открытия и порядка сторон,
не хранится второй копией. Поздняя ошибка откатывает также журнал.

Own forecast передаёт по колонии готовую разбивку:
база, число работников, выпуск труда, вклад технологий, предел, итог
и IDs применённых effects. Демография отдельно передаёт K и ставку.
Desktop/mobile не умножают научных/культурных рабочих повторно.
AI оценивает предельную пользу по той же own-only проекции с учётом caps;
фиксированные веса старых hull/family/tier остаются отдельной эвристикой.
Baseline суммирует рассчитанные K, не число колоний×старую константу.
