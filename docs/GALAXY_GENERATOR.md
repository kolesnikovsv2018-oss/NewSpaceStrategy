# Генератор галактики: формат, CLI и браузерная кампания

## Статус и границы

Г01–Г03 предоставляют автономную модель карты, чистый генератор и CLI. Н05/Г04 подключают его к браузерной кампании для двух участников. Д08 заменил линии [прямыми дистанционными перелётами](CAMPAIGN_TRAVEL.md); Н14 добавил проектные скорость/время/fuel; P>2/Н17 в игре ещё не реализован. Мирная песочница сохраняет фиксированную карту.

Одна запись `world` обозначает одну систему с одной планетой. Формат принимает только `orion-galaxy-map`, schema/rules version4 и `galaxy-generator-v4`. Иные версии и поля `lanes` отклоняются без преобразований/fallback.

## Профиль `balanced-start-v4`

- `worldCount`: 6–256 для профиля двух участников, в общем случае минимум `3 × participantCount`.
- Участников 2–8; CLI без `--participants` использует 2. Каждый имеет ровно один отдельный домашний мир.
- Каждому дому резервируются два ближайших нейтральных пригодных мира в пределах начальной дальности200. Реальный начальный комплект100 speed/200 jump/3000 тысячных fuel проверяется общим route quote.
- Дома и гарантированные цели habitable. Дополнительные E дают C=floor(70E/100) потенциальных целей; из них T=0 при E<2, иначе min(C,max(1,floor(20E/100))) toxic. Остальные C−T habitable, E−C barren. [Правила Н10](CAMPAIGN_PLANETOLOGY.md).
- Координаты лежат в квадрате `[0,1000] × [0,1000]`, разделение≥10; евклидово расстояние задаёт сортировку и проверку дальности, а также тариф/длительность по общему [контракту Н14](CAMPAIGN_TRAVEL.md).
- Сетевой топологии, линий и степени узла нет. Любая пара миров потенциально доступна; технологическая дальность1500 покрывает всю карту.
- `initialTravel` сохраняет project-travel-v1, strategicSpeed100, maxJumpDistance200, fuelCapacity3000, fuelConsumptionPerDistance5. Все ID и массивы каноничны.

## API модели

В `src/domain/galaxyMap.ts` находятся schema/checker/codec и nearest/initial-reach queries. Checker проверяет количество/уникальность миров и участников, координаты/разделение, владение только домами, точные доли типов и две ближайшие доступные начальной дальности цели каждого игрока. Проверки линейного графа удалены.

`src/domain/galaxyGenerator.ts` экспортирует чистую `generateGalaxy(unknown)`. Request strict: `worldCount`, `participantCount`, `seed` (1…2³²−1), `generatorVersion` и `profileId`. Доменные генерация и валидация не обращаются к IO, часам или глобальному RNG.

## CLI

```sh
yarn generate:galaxy --world-count 40 --participants 4 --seed 12345 --output ./maps/galaxy.json
yarn generate:galaxy --world-count 40 --output ./maps/galaxy.json
```

При отсутствии `--participants` используется 2, без `--seed` CLI один раз создаёт seed криптографическим источником Node и сохраняет его в карте. `--output` обязателен, путь должен оканчиваться на `.json`; существующие файлы не перезаписываются.

CLI строит и валидирует JSON до обращения к целевому пути, создаёт эксклюзивный временный файл в каталоге назначения, затем публикует жёсткую ссылку без перезаписи. Ошибка генерации/записи приводит к ненулевому коду, stdout сообщает об успехе только после записи. JSON — UTF-8; русские/английские названия сохраняются как Unicode, а не `\u` escapes. Искусственный лимит размера файла не установлен. Требуются существующий каталог назначения и файловая система, поддерживающая hard links.

CLI запускается существующей установленной Node из Yarn script; его собственный TS config включает Node-типы, не добавляя их в браузерный source build. Node-режим CLI проверяется отдельными настоящими subprocess-тестами.

## Проверки

- `tests/galaxyMap.test.ts`: строгий актуальный формат, Unicode round-trip, отказ иной версии, повреждённые ссылки/миры, nearest-k и detached decode.
- `tests/galaxyGenerator.test.ts`: 100 фиксированных seed для наборов 6/2, 64/4, 256/8, полный checker и стартовые гарантии.
- `tests/galaxyCli.test.ts`: настоящие процессы Node, реальные UTF-8 файлы в изолированном временном каталоге, автогенерация seed, collision, invalid input и отказ записи.

Эти три файла проверяют формат/генератор/CLI. Подключение к игре отдельно покрывают `tests/galaxyCampaign.test.ts` и `tests/conquestScene.test.ts`: оплаченные перелёты обеих сторон, законные AI-победы, независимые снимки, mining/scanner/бой, ошибки хранения и lifecycle. CLI-тест сравнивает реальный файл с браузерным результатом побайтово.

## Запуск в браузере

Меню → **«Новая кампания»** → настройки новой игры. Выберите 6–256 миров и local либо игру против компьютера; число участников отображается, но заблокировано на 2. По умолчанию 40 миров. Дерево исследований можно заменить актуальным YAML/JSON, как прежде. Прежняя фиксированная галактика доступна отдельно: **«Демонстрации» → «Мирная песочница»**; генератор там не запускается.

`BrowserGalaxyGenerator` передаёт явный seed и два участника в общую `generateGalaxy`; собственных алгоритмов размещения/связности у него нет. Seed получается один раз через Web Crypto и виден на карте/в JSON. Для одинаковых N/P/seed/профиля CLI и браузер сохраняют одинаковые канонические байты.

После полной проверки карты и кандидата партии `LocalGalaxyMapRepository` выполняет один `setItem` в `orion_galaxy_map_v1`. Только затем запускается кампания. Слот содержит полный JSON последней **созданной** карты, не библиотеку и не прогресс. Ошибка доступа/квоты показывается в диалоге; прежняя партия/карта остаются. Отмена до старта не вызывает генерацию или IO. Атомарность отказа обеспечивает localStorage/StoragePort; межвкладочный CAS отсутствует.

`GalaxyMapRepository` отделяет save/load от сцены и допускает Promise-результаты. Репозиторий можно передать конструктору сцены. Будущий серверный адаптер должен соблюдать тот же формат, явные ошибки и lifecycle; backend, сетевые запросы и автоматическая загрузка последней карты сейчас не реализованы.

Канонический map snapshot находится в `session.galaxy.map`; `player-01` соответствует blue, `player-02` — red. Массив runtime `systems` отдельно хранит текущее владение/знание. Исходное владение в JSON не изменяется при захватах. Каждая партия владеет своим независимым снимком; нет изменяемой глобальной галактики.

Conquest save12/rules9 хранит начальную карту, environment/surveys, проекты, rules snapshot7/7, население/остаток, назначения/выпуск, tree6 и журнал. Load не читает latest-map и не генерирует карту; иные военные версии отвергаются.

Мини-карта показывает миры без линий. Адаптивный picker выбирает любой мир и показывает прямое расстояние/причину недоступности. Основная кампания использует принятую адаптивную раскладку Н02 на1280×720/390×844.

На карте действует distance-only-v1:1 топлива, own-end arrival, бак3. Победа требует исходные habitable+toxic, независимо от runtime/unlock. Checker начального профиля не используется для проверки изменённой runtime-среды.
