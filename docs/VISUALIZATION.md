# Визуализация кораблей

## Обзор

Система визуализации кораблей включает интерактивные графические элементы для отображения состояния и характеристик космических кораблей.

## Компоненты визуализации

### 1. ShipSprite

Основной класс для визуального представления корабля на игровом поле.

**Особенности:**
- Динамическая отрисовка корабля на основе его компонентов
- Цветовая кодировка по типу корабля
- Анимация свечения двигателей при движении
- Полоска энергии
- Визуализация установленного оборудования
- Эффект выделения при клике

**Цвета кораблей:**
- 🟢 Зеленый - Разведчик
- 🟠 Оранжевый - Грузовоз
- 🔴 Красный - Крейсер
- 🟡 Желтый - Добытчик
- 🔵 Синий - Другие

**Элементы визуализации:**
- Основной корпус (треугольник)
- Крылья/боковые части
- Кабина (голубой круг)
- Грузовой отсек (оранжевый прямоугольник, размер зависит от вместимости)
- Точки оборудования (фиолетовые круги)
- Свечение двигателей (при движении)
- Полоска энергии (цвет зависит от уровня)

**Интерактивность:**
- Клик для выделения и показа информации
- Курсор меняется при наведении
- Автоматический поворот по направлению движения

### 2. ShipInfoPanel

Информационная панель с детальной информацией о выбранном корабле.

**Отображаемая информация:**
- Название корабля
- Общие характеристики (стоимость, вес, скорость, дальность)
- Источник энергии (название, запас, генерация)
- Двигатель (название, тяга, потребление)
- Грузовой отсек (вместимость, загруженность)
- Список установленного оборудования
- Визуальные иконки компонентов

**Иконки компонентов:**
- 🟡 Круг - Источник энергии
- 🔵 Треугольник - Двигатель
- 🟠 Квадрат - Грузовой отсек

## Использование

### Создание визуального представления корабля:

\`\`\`typescript
import { ShipSprite } from './entities/visuals/ShipSprite';
import { ShipFactory } from './entities/ShipFactory';

// Создать корабль
const ship = ShipFactory.createScout();

// Создать визуальное представление
const shipSprite = new ShipSprite(this, ship);

// Обработка кликов
shipSprite.on('pointerdown', () => {
  shipSprite.setSelected(true);
  console.log(shipSprite.showInfo());
});

// Обновление в игровом цикле
update(time: number, delta: number) {
  const deltaSeconds = delta / 1000;
  shipSprite.update(deltaSeconds);
}
\`\`\`

### Использование информационной панели:

\`\`\`typescript
import { ShipInfoPanel } from './ui/ShipInfoPanel';

// Создать панель
const infoPanel = new ShipInfoPanel(this, 20, 20);

// Показать информацию о корабле
infoPanel.showShipInfo(ship);

// Скрыть панель
infoPanel.hide();

// Обновление панели
update() {
  infoPanel.update();
}
\`\`\`

## Тестовая сцена

`ShipTestScene` - демонстрационная сцена для тестирования визуализации.

**Особенности:**
- Создает 4 корабля разных типов
- Интерактивный выбор кораблей
- Отображение детальной информации
- Демонстрация движения
- Звездный фон

**Управление:**
- Клик на корабль - выбрать и показать информацию
- ESC - закрыть панель информации
- Курсор меняется при наведении на корабль

## Визуальные эффекты

### Полоска энергии
- 🟢 Зеленая (> 50%) - достаточно энергии
- 🟠 Оранжевая (20-50%) - средний уровень
- 🔴 Красная (< 20%) - критический уровень

### Свечение двигателей
- Отображается только при движении
- Интенсивность зависит от скорости корабля
- Два двигателя (левый и правый)
- Цвет: голубой с белым ядром

### Круг выделения
- Желтая окружность вокруг выбранного корабля
- Пульсирующий эффект для привлечения внимания
- Радиус 35 пикселей

## Адаптивность

Визуализация автоматически адаптируется к характеристикам корабля:

- **Размер грузового отсека** зависит от его вместимости
- **Количество точек оборудования** равно количеству установленных модулей
- **Интенсивность свечения** двигателей зависит от скорости
- **Цвет энергии** зависит от текущего уровня

## Производительность

Оптимизации:
- Графические элементы группируются в контейнеры
- Перерисовка только при изменении состояния
- Использование Graphics API для простых форм
- Минимальное количество текстур
