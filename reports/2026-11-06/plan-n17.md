## Утверждённые продуктовые решения (Н17.1, подтверждены пользователем 2026-11-06)

- **Диапазон P = 2..8** (`MIN/MAX_PARTICIPANTS`); минимум миров ≥ 3×P enforced
  генератором и границей кампании; нижний предел миров в UI = max(6, 3×P).
- **Идентичность**: `player-01..player-0P` из снимка карты, порядок = порядок массива
  participants; enum blue/red не используется новой политикой.
- **Metadata**: save-блок `participants` `{id, name, color}`; имя из карты, палитра
  по позиции (0x55baff, 0xf08070, 0x7fd76a, 0xf2d24b, 0xb07fe8, 0x4fd6c0, 0xe86bb0,
  0x9aa8c0); UI не выводит цвета/имена из enum.
- **Расписание**: ordered participants, active index/фаза; активная сторона из
  расписания, не из parity; turn монотонно растёт на выполненный или пропущенный
  ход; round = полный круг; единая точка дипломатического раунда — после endTurn
  последнего участника круга (Н17.4).
- **Elimination**: выбытие только без колоний и без кораблей (включая транзит);
  производное состояние без сохраняемого флага; пропуски продвигают turn/round и
  сроки договоров; победа остаётся all-planets-v1 без новых условий.
- **Encounter policy**: `encounterPolicy: 'conquest-encounters-v2'` — отдельное поле
  схемы; deterministic pairwise последовательность двухсторонних боёв реальным
  BattleManager; порядок пар по расписанию, циклы до отсутствия враждебных сторон;
  отчёты — только фактические пары, одновременный бой не объявляется.
- **Дипломатия per pair**: семантика Н16 на каждую пару; лимиты per pair = значения
  Н16 (pending ≤1/сторона/пара, история 24/пара, договоры 12/пара, журнал 64/пара);
  явный получатель `player-NN`; атомарный обмен per pair; treaty gate по паре.
- **Контроллеры**: `{mode:'local'}` либо `{mode:'campaign', human:'player-NN',
  aiPolicy:'conquest-v1'}`; прежние human-vs-ai отклоняются после bump; takeover →
  local; один bounded AI-пакет (≤24 действий) на активного AI, один ticket.
- **Пределы**: per-faction прежние (100 кораблей, 20 групп); глобальные пределы
  массивов = фиксированные константы per-faction × MAX_PARTICIPANTS (800/160),
  без множителя «×2».
- **Мирная песочница**: campaignMatch/joint-survey не мигрирует, формат прежний.
- **Версии**: старт 18/15/13 → цель save 19 / rules 16 / rulesSnapshot 14; финальные
  номера — по факту изменений Н17.2–Н17.5; прежние версии — явный отказ.
- **Диагностика**: двухсторонний cutoff 200 не переписывается; горизонты P=3/max
  согласовываются отдельно в Н17.7 до прогонов.

## Гейты и правила

- Каждый подэтап: целевые тесты, `yarn typecheck`, `yarn build`; полный `yarn test`
  — при общей схеме/кодеке/формулах и в Н17.2/Н17.6/Н17.8.

  явный отказ; фикстуры обновляются в том же подэтапе (прецедент upgrade-n15-fixtures).
- Н-граф не меняется: Н18 требует Н17 целиком; Н17.8 — единственная точка статуса
  «Выполнено» в журнале; коммит/push только по прямому запросу.
- Все изменяемые величины — через rules snapshot; числа решений — только из
  `docs/CAMPAIGN_MULTI_FACTION.md` и родителя, без новых молчаливых default.
