## Цель и границы

Проверить все 21 задание в [комплекте](../../plans/tasks-2026-10-09/README.md) по текущему коду, учесть принятую генерацию карты кампании и исключить обязательные зависимости от следующих этапов. Исправлены задания, общий контракт, указатель и связанные планы. Исходники, тесты, зависимости и сохранённые пользовательские данные этой задачей не изменялись.

В рабочем дереве уже были изменения реализации генератора, кампании, меню, документации и навыков. Они прочитаны как фактическая отправная точка и сохранены; сводный git diff относительно HEAD не является перечнем изменений только этой задачи.

## Изменения и решения

Проверены [galaxyMap](../../src/domain/galaxyMap.ts), [galaxyGenerator](../../src/domain/galaxyGenerator.ts), [campaign](../../src/domain/campaign.ts), [campaignShips](../../src/domain/campaignShips.ts), [campaignResearch](../../src/domain/campaignResearch.ts), [conquest](../../src/domain/conquest.ts), [ConquestScene](../../src/scenes/ConquestScene.ts), [MenuScene](../../src/scenes/MenuScene.ts), [GalaxyMapRepository](../../src/utils/GalaxyMapRepository.ts), [ConquestSaveManager](../../src/utils/ConquestSaveManager.ts) и связанные тестовые сценарии/контракты.

Фактическая база: главный вход генерирует 6–256 миров для двух сторон; общий формат/CLI поддерживает 2–8 участников. Map schema/rules 1/1, линии — пары ID без длины. Военный save 5/3 содержит tree2 и явную battlePolicy; map snapshot отделён от меняющегося ownership/knowledge. Latest-map repository допускает Promise; load кампании не использует этот слот. Конструктор стороны, демография, point-based science, изменяемая среда, refit и дипломатия ещё не реализованы.

Общие уточнения в [контракте исполнения](../../plans/tasks-2026-10-09/00-execution-contract.md):

- Прямые предпосылки и их транзитивное замыкание — единственные обязательные предыдущие этапы. Номер задания не требует завершения всех ранних независимых ветвей.
- Новый handler/поле/потребитель поставляется в своём этапе, без заглушки до следующего. Н03-runner обновляется только после принятого Н03; иначе достаточно самостоятельных регрессий.
- Игровые этапы расширяют единственный Conquest и обязательный генераторный старт, не параллельный основной режим. Ручные контрольные fixtures не означают уже существующий UI-импорт карт.
- Начальная карта неизменна; будущая текущая среда принадлежит runtime state. До Н18 военные цели закрепляются по исходным пригодным мирам, не меняются при unlock/terraform.
- `code/message` — требование новых границ, не ложное описание нынешнего преимущественно `ok/message` API. Не затронутые исторические readers не переписываются внутри документационной/UI-задачи.
