# 01 — Единый вход в кампанию и раздел демонстраций

- Дата: 2026-10-10
- Пункт плана: уточнение навигации после Н05/Г04 по прямому запросу пользователя
- Статус: выполнено

## Цель и границы

Убрать конкурирующие основные входы «Галактика»/«Военная кампания». Основной игровой процесс развивается в единой кампании с исследованиями, экономикой и боями. Прежние демонстрационные сценарии остаются доступными, но не представлены как альтернативная основная игра.

Задача меняет навигацию, не доменные правила, генератор, форматы сохранения или тактическую симуляцию. Население, научная экономика и дипломатия из будущих Н-этапов не реализованы этим изменением.

## Изменения и решения

- [MenuScene](../../src/scenes/MenuScene.ts): основное меню содержит «Новая кампания» → ConquestScene, «Верфь» → ShipyardScene и «Демонстрации».
- Раздел демонстраций содержит «Мирную песочницу» → MainScene, «Испытание кораблей» → ShipTestScene и «Испытание боя» → BattleScene. «Назад»/Escape возвращают в основное меню, не запускают сцену и не выполняют IO.
- Сохраняется идентификатор `start-conquest` для основного входа и `start-campaign` для перенесённой песочницы. Испытания получили явные имена кнопок.
- Общий helper сохраняет единые hover-стили. Контейнер предыдущего экрана уничтожается; render generation делает захваченные старые callbacks инертными после перехода/shutdown/reentry. Shutdown удаляет собственный ESC-handler.
- Добавлены [9 регрессий меню](../../tests/menuScene.test.ts). Согласованы [README](../../README.md), [контракт кампании](../../docs/CAMPAIGN_CONQUEST.md), [инструкция генератора](../../docs/GALAXY_GENERATOR.md) и [научно-ориентированный план](../../plans/plan-2026-10-09.md).
- Мирная песочница остаётся отдельным демонстрационным сценарием. Механического объединения её state/save с Conquest нет; общий ручной слот и отказ неподходящего формата не менялись.

Обычный sandbox-запуск Yarn остановился до выполнения на Snap/cgroup startup failure. VS Code test tool не обнаружил Vitest-тесты. Фактические проверки выполнены через VS Code shell task без установки зависимостей.

Браузерная вкладка сообщала `visibilityState=hidden`; RAF заменён несколькими диагностическими `game.step`. Попытки mouse-click не подтвердили переход, поэтому браузерная приёмка выше основана на программных Phaser pointer-событиях, не mouse-E2E. Скриншот подтверждает основную раскладку. Mobile проверен после перезагрузки, не как бесшовная смена размера работающей вкладки. Прежний мелкий Scale.FIT сохраняется. Полный набор3308 тестов повторно не запускался: минимальная связанная выборка, strict typecheck и production build покрывают ограниченное изменение.

Проверка ссылок обнаружила неизменённые исторические ссылки README на отсутствующий `reports/2026-09-07/plan.md` (три упоминания). Они присутствуют в HEAD и не относятся к новой навигации; не исправлялись в этой задаче. Все новые ссылки существуют.
