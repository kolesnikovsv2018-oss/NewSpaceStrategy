# 08 — Интерфейс стратегических перелётов

- Дата: 2026-09-09
- Пункт плана: S3.10
- Статус: выполнено

## Цель и границы

Подключить sendShip к UI: выбрать свой стационарный корабль, соседнюю собственную цель, отправить и видеть собственные маршруты/прибытие. Сохранить доменные правила S3.9, приватность, captured payload и lifecycle. Без топлива, содержания, группировки, боя, AI или сохранения кампании.

## Изменения и решения

- [TravelPanel](../../src/ui/TravelPanel.ts) — отдельная компактная панель внутри производства, только SessionView/callbacks. Верхние страницы собственных стационарных кораблей, выбор соседней своей цели по projected lanes, кнопка отправки. Нижние страницы всех собственных transit с ID/именем, маршрутом и1 своим ходом. Нет кнопок перенаправления; transit не попадает в список отправки.
- [ProductionPanel](../../src/ui/ProductionPanel.ts) владеет новой дочерней панелью; «Перелёты» заменяет очередь, «← Производство» возвращает её. Это отдельный экран, не наложение на три производственных заказа. Destroy всей цепочки делает прежние callbacks инертными.
- [MainScene](../../src/scenes/MainScene.ts) хранит travelOpen/destinationIndex/transitPage и общий shipsPage. Кнопка замыкает показанные shipId/destinationId, сцена — factionId/systemId/expectedTurn; вызов только через executeSessionCommand. Успех выбирает новый маршрут, корабельная страница ограничивается оставшимися записями, после прибытия страница пустого transit становится0.
- Нет корабля/цели — отправка disabled. Неактивная сторона или изменившееся состояние получают реальный доменный отказ без частичного принятия. Нижний список охватывает всю наблюдаемую сторону, чужих маршрутов нет даже после разведки.
- Смена корабля сбрасывает цель; сторона/колония/карта/reset/shutdown очищают travel state. Каталог навигацией не перечитывается. Pending блокирует controls; ESC: отмена pending → перелёты в производство → производство на карту → подтверждение меню. Snapshot библиотеки и проект не меняются.
- Имена сокращаются по реальному text.width до745 px, подпись цели400 px; большие ID и полные проекты сохраняются. [CampaignPanel](../../src/ui/CampaignPanel.ts) показывает S3.10 и актуальные ограничения. Правила domain/campaignShips/session не изменялись.
