## Цель и границы

Добавить минимальную экономику и явное завершение хода: независимые казны, доход только нужной стороне по её колониям, строгий порядок действий и численные ограничения. Это следующий модельный шаг [плана](../2026-09-07/plan.md), не реализация всей кампании.

UI экономики, производство/очереди, расходы/содержание, флоты/миссии, AI, исследования, сохранение и интеграция боя не входят. Текущая карта S3.2 продолжает работать как песочница без ходов и ресурсов до следующего шага; это отмечено в текущей документации, не скрыто как выполненная интеграция.

## Изменения и решения

- Новый [campaignSession.ts](../../src/domain/campaignSession.ts) содержит CampaignSession с одной galaxy, номером turn и казнами blue/red. Нет Phaser, часов, RNG, БД/localStorage или зависимости от моделей корабля.
- В [campaign.ts](../../src/domain/campaign.ts) экспортирована существующая factionIdSchema для переиспользования; прежние схемы/правила/поведение sandbox API не изменены. Сессионные explore/colonize расширяют существующие схемы обязательным expectedTurn и делегируют географические правила прежнему исполнителю.
- Новый [campaignSession.test.ts](../../tests/campaignSession.test.ts) закрепляет 60 сценариев. Зависимости, lock-файл, UI и формат библиотеки кораблей не менялись; накопленные локальные изменения сохранены.

### Принятые правила

| Параметр | Значение и смысл |
| --- | --- |
| Казна | Кредиты и минералы — независимые целые ресурсы 0..1 000 000 000, без приведения строк/null |
| Старт | У каждой стороны 100 кредитов/50 минералов, turn1/blue; дополнительного стартового дохода нет |
| Доход | Каждая текущая своя колония даёт 10 кредитов/5 минералов при собственном endTurn |
| Новые колонии | Учитываются уже при завершении текущего хода; разведка/колонизация сами денег не начисляют |
| Очередность | Нечётный turn — blue, чётный — red. Один turn — действия одной стороны, не полный раунд |
| Команды карты | Бесплатны/без лимита действий, но в сессии только активной стороной. Нет цены колонизации или флота-колонизатора |
| Предел хода | 1..1 000 000 000; невозможность увеличить отклоняет весь endTurn |

Казна противника и его доход не меняются при завершении своего хода. Чужие/нейтральные разведанные системы не дают дохода. Ноль колоний означает ноль дохода без автоматического поражения. Баланс предварительный; минералы не связаны с грузом или исполнением mining, стратегический ход не связан с миллисекундами тактики.

### Контракты и атомарность

`executeSessionCommand` проверяет unknown state/command, expectedTurn и действующую сторону, затем исполняет действие. Ошибки возвращаются как ok:false/code/message без частичного state; успех — отдельное полное состояние. Входные вложенные объекты не меняются, включая frozen-вход.

`endTurn` сначала проверяет оба итоговых ресурса и возможность увеличить номер хода, только затем применяет доход/переход. Переполнение хотя бы одного ресурса отменяет всё: нет частичной выплаты, clamp или смены стороны. Точное достижение предела допустимо. Пока расходов нет, достижение cap может блокировать дальнейший endTurn — явная техническая граница прототипа, не условие победы.

expectedTurn обязателен для всех команд. Повтор старой команды на обновлённом состоянии отклоняется, даже когда прежняя сторона снова активна. Caller обязан принять результат: повтор на старом снимке детерминированно воспроизводит результат; это не ID партии/request-id, не сетевая дедупликация и не revision каждого действия внутри хода.

`getCampaignSessionView` возвращает только собственные казну/доход запрошенной стороны и её CampaignView; turn/activeFactionId публичны. Даже разведанная чужая колония не раскрывает казну противника. Запрос не платит доход и отдаёт независимые объекты. Неверные запросы бросают ZodError; команды возвращают типизированный отказ. Схемы runtime, не сохранения кампании с миграциями.
