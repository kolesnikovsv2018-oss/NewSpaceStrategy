# 07 — Ограниченный стратегический перелёт

- Дата: 2026-09-09
- Пункт плана: S3.9
- Статус: выполнено в ограниченных границах модели, без UI отправки

## Цель и границы

Отправлять один корабль между соседними собственными колониями и завершать перелёт за один свой успешный endTurn. Сохранить ID/проект, очередность, приватность, лимиты и атомарность всей команды. Не добавлять тактический runtime, топливо, содержание, группировку, бой, AI, save или пользовательские кнопки отправки.

## Изменения и решения

- [campaignShips.ts](../../src/domain/campaignShips.ts): optional `transit = { destinationId, remainingTurns: 1 }`, строгая схема перехода. Без transit `systemId` — место стоянки, с transit — исходная колония, не физическое присутствие. Отдельные status/sourceId не дублируются. `isShipAtColony` исключает корабль в пути из обеих колоний; `advanceShipTravel` возвращает независимый список с прибывшими собственными кораблями.
- [campaign.ts](../../src/domain/campaign.ts): `areSystemsAdjacent` переиспользует существующие двусторонние lanes, без второй топологии или pathfinder.
- [campaignSession.ts](../../src/domain/campaignSession.ts): строгий `sendShip` с factionId/expectedTurn/systemId/shipId/destinationId. Проверки schema→turn→active→own source→own ID в источнике→не в пути→own target→соседство. Новые SHIP_NOT_FOUND/SHIP_IN_TRANSIT/INVALID_ROUTE; чужая/нейтральная цель получает NOT_OWN_COLONY до проверки маршрута.
- Отправка не меняет номер хода, казны, производство, галактику, ID, проект или количество кораблей. Повтор/перенаправление запрещены. Текущие own endpoints валидируются сессией; захвата нет, потеря ownership делает вход недопустимым.
- Успешный собственный endTurn завершает все собственные transit, включая отправленные в этом ходу; чужой их не двигает. Прибытие меняет systemId и удаляет transit. Проверки пределов дохода/хода выполняются до дохода, производства и прибытия; отказ не возвращает частичный state и не меняет вход.
- Лимит100 ships включает корабли в пути, ID не освобождается и не пересекается с orders/completed. MAX_ORDER_ID не препятствует полёту; MAX_TURN не запрещает отправку, но запрещает последующий endTurn — техническая граница прототипа.
- [MainScene](../../src/scenes/MainScene.ts) и [ProductionPanel](../../src/ui/ProductionPanel.ts) фильтруют присутствующие корабли через общий селектор; общий счётчик включает transit. Добавлено отдельное сообщение отправки. [CampaignPanel](../../src/ui/CampaignPanel.ts) и подсказка производства уточняют: модель перелёта есть, кнопок и боя нет.
- Прежние стационарные записи S3.8 без transit валидны без автоматического добавления поля. Сессии без обязательных ships/production по-прежнему INVALID_STATE. Миграции/формата сохранения не добавлено. Полётный snapshot не меняет канонические формулы/валидаторы корабля или боевую энергию.
- [Правила кампании](../../docs/CAMPAIGN.md), [README](../../README.md) и [план](../2026-09-07/plan.md) согласованы; S3 целиком остаётся открытым. Зависимости/lockfile не менялись; накопленные локальные изменения сохранены, коммитов/публикации нет.
