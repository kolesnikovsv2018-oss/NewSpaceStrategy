- Дата: 2026-09-09
- Пункт плана: S3.15
- Статус: выполнено

## Цель и границы

Подключить правила S3.14 к интерфейсу своей колонии: выбор свободных кораблей, создание/просмотр групп и участников, расформирование. Сохранить строгие команды, приватность, лимиты и жизненный цикл панелей. Групповой перелёт, изменение состава, снабжение/содержание, стратегический бой, AI и save не входят. Доменные правила и баланс топлива не менялись.

## Изменения и решения

- [FleetPanel](../../src/ui/FleetPanel.ts) — независимая панель на SessionView. Свободные стоящие ships своей колонии, выбор по ID/страницы, выбранность/топливо/счётчик0..10, «Убрать»/«Очистить» и create при2+. На10 добавление11-го отключено, снятие выбора доступно.
- Нижняя часть: страницы групп выбранной колонии, ID/число участников и общий own count/20, отдельные страницы каждого участника по ID/имени/fuel. Disband немедленный без подтверждения: операция бесплатна, корабли остаются. Пустые списки отключают controls. Лимит групп/ID/неактивная сторона показывают доменный отказ через доступную кнопку.
- [ProductionPanel](../../src/ui/ProductionPanel.ts) владеет новой дочерней панелью, вкладки групп/перелётов/очереди взаимоисключающие. Новая кнопка x350/y216, заголовок ограничен290px. Имена кандидата745px/участника590px сокращаются по реальной text.width, исходные snapshots не меняются.
- [MainScene](../../src/scenes/MainScene.ts) хранит только UI draft массива ID и страницы. Create захватывает независимый показанный массив; disband показанный ID; сцена захватывает factionId/systemId/expectedTurn. Новое состояние принимается только при ok. При create draft очищается/показывается новая группа; disband сбрасывает страницу участника. Render ограничивает страницы и удаляет недопустимые выбранные ID, отказ сохраняет оставшийся допустимый выбор.
- Успешный endTurn очищает draft. Смена стороны/колонии/карты/перелётов, закрытие групп/reset/shutdown очищают выбор/страницы. Pending блокирует controls, отмена сохраняет выбор. ESC последовательно отменяет pending, закрывает группы в очередь, очередь на карту, запрашивает меню. Destroy каскадный, callbacks старой панели инертны.
- [TravelPanel](../../src/ui/TravelPanel.ts) показывает ID группы выбранного участника и подсказку о расформировании перед send. Refuel остаётся доступной по прежним правилам. [CampaignPanel](../../src/ui/CampaignPanel.ts) обновляет подпись этапа.
- [campaignScene.test.ts](../../tests/campaignScene.test.ts) —29 новых регрессий. Доменные файлы, корабельная библиотека, зависимости/lockfile и тактические модели не изменялись.

### Браузер: обычный игровой путь

В видимой вкладке событиями существующих кнопок обе стороны основали соседние колонии, накопили доход и оплатили по два истребителя185/11. FIFO завершён к turn45, проекты сохранены для сравнения. Синие корабли ID1/2 размещены в Соле; попытка разместить красные в том же синем ходу корректно отклонена, красные ID3/4 размещены позже на своём turn46 в Веге. Подстановки ресурсов/колоний/кораблей в этом сценарии нет.

Мышью на turn45 открыты «Группы», выбраны ID1/2, создана группа1. Мышью проверена страница второго участника, вкладка «Перелёты» и отказ send участника; затем расформирование группы1 и успешный одиночный send ID1 с fuel3→2. Казна при групповых действиях неизменна; после обычного endTurn корабль прибыл в Эдем.

Красные корабли размещены событиями кнопок на turn46. Мышью выбраны ID3/4 и создана группа2, мышью завершён красный ход, затем попытка disband отклонена «Сейчас ход другой стороны» на turn47; группа сохранена. Оплаченные snapshots всех четырёх проектов и localStorage неизменны. Скриншот групповой панели осмотрен, наложений controls/текста в проверенном состоянии нет.

### Браузер: диагностические пределы и очистка

Снимок обычной партии временно сохранён. Для проверки крайних состояний подставлены100 красных ships,20 групп, ID до1e9, имена по80 символов и активный красный ход. Эти данные **диагностические, не произведённые за игровые ресурсы**.

Программно выбраны10 свободных кораблей: добавление11-го отключено, create показывает FLEET_LIMIT без сброса допустимого выбора. Просмотр20-й группы, имя кандидата744px и участника577px, полный ID группы1e9; скриншот осмотрен, текст не пересекает кнопки. Pending отключает новые controls/вкладки; сохранённый старый callback disband не действует, state неизменен. ESC отменяет pending и сохраняет выбор10/10.

Исходная партия восстановлена. ESC закрывает группы в очередь, затем на карту. Reset даёт turn1/0ships/fleets{0,[]}. Выход освобождает сессию/0children/0ESC; повторный вход — одна panel/ESC/canvas, пустой draft и закрытая вкладка групп. Временные снимки удалены, localStorage неизменен.

Это **не полный mouse E2E**: подготовка/часть навигации программными событиями, граничные состояния подставлены явно. Ручной game.step не использован. Fake Phaser не выдаётся за browser hit testing; FPS и баланс партии не измерялись. Групповая заправка/перелёт не реализованы и не проверялись как готовые возможности.
