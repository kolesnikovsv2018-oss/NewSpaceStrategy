- Статус: выполнено в согласованных границах.

## Цель и границы

Сделать выбор миров на плотной галактической карте удобнее: масштабирование
колесом и кнопками, перенос, возврат общего обзора. По подтверждению
пользователя изменены и основная военная кампания, и мирная демонстрация.
На телефоне добавлено отдельное окно карты основной кампании.

Симуляция, доменные координаты, расстояния, видимость, AI, генератор,
экономика и форматы сохранений не изменены. Н15–Н20 этой задачей
не реализованы. Pinch и адаптация всей мирной демонстрации под телефон
не входят в поставку.

## Изменения и решения

- [GalaxyMapViewport](../../src/ui/GalaxyMapViewport.ts) содержит чистые
  fit/project/unproject/zoom/pan/focus/clamp. Относительный масштаб
  1–16, шаг×1,25, ограничение границ и обработка вырожденных координат.
- [GalaxyMapWidget](../../src/ui/GalaxyMapWidget.ts) — общий компонент:
  колесо к указателю, +/− к центру, процент, «Вся карта», перенос мышью
  или одним пальцем, выбор на коротком нажатии. Перенос от5 логических
  пикселей подавляет выбор. Hit testing использует ту же проекцию;
  ближайший маркер выбирается стабильно, включая равенство по ID.
- Масштабируются позиции, но не размеры текста/controls. Графика
  ограничена viewport маской, ввод за его пределами не действует.
  Wheel/drag перерисовывают только widget, не всю сцену.
- [ConquestScene](../../src/scenes/ConquestScene.ts): включён прямой
  выбор точек сгенерированных карт, ранее неинтерактивных. Desktop имеет
  обзор и кнопку «Развернуть карту», mobile — «Карта галактики» во вкладке
  «Мир». Список миров сохранён. Modal использует прежний ESC/resize/AI
  lifecycle; выбор закрывает окно.
- [MainScene](../../src/scenes/MainScene.ts) владеет навигацией мирной
  карты, [CampaignPanel](../../src/ui/CampaignPanel.ts) — экземпляром
  widget. Линии переходов сохранены; бюджет/производство скрывают карту
  и освобождают её обработчики.
- Несохраняемое UI-состояние переживает redraw, смену вкладки/панелей
  и обычный ход. New/load сбрасывают его; resize сохраняет относительный
  zoom/центр с clamp, но отменяет открытый modal. Выбор вне области
  фокусируется без сброса масштаба.
- Обновлены [руководство](../../docs/CAMPAIGN_UI.md),
  [описание мирной карты](../../docs/CAMPAIGN.md) и
  [встроенная справка](../../src/ui/ConquestWidgets.ts), теперь6 страниц.

### Исправления, найденные во время проверки

Первый браузерный прогон выявил повторный destroy контейнера из его
destroy-event: Phaser сначала выполняет preDestroy и удаляет children.
Очистка handlers/mask теперь отделена от вызова root.destroy и выполняется
ровно один раз. Дополнительно подтверждены отключение фонового input
при pending и синхронизация обзора после закрытия развёрнутой карты.
Эти дефекты исправлены и перепроверены; известных блокирующих ошибок
Д17 не осталось.

## Настоящий браузер

Проверка выполнена Playwright в headless Microsoft Edge / Chromium155,
в изолированном временном browser context. Настоящие DOM mouse/wheel
и CDP touch-события проходили через Phaser; не прямой вызов callback
вместо pointer-проверки. Touch включён до загрузки игры.
Использован точный URL существующего main-script, без второй игры.

| Сценарий | Фактический результат |
| --- | --- |
| CSS1280×720,40 и256 миров | Колесо/+−,100/1600%, pan без выбора, anchor/clamp oracle, реальный выбор после zoom>3× и переноса прошли |
| CSS1280×720,6 миров | Контрольный старт, zoom limits, колесо/pan, выбор в общем обзоре и неизменность state прошли; отдельный high-zoom выбор6 не заявляется |
| CSS390×844,256 миров | Окно карты, +/−/«Вся карта», настоящий эмулированный touch-pan с изменением центра без выбора, выбор мира/закрытие/ESC прошли |
| Геометрия mobile | +/−44×44, «Вся карта»120×44, закрытие366×44; шрифт14px; CSS canvas390×844 |
| Resize | Переход desktop→mobile→desktop; окно отменяется, партия сохранна |
| Военный save/reload/load | Полный state равен сохранённому, несохраняемый viewport вернулся к100% |
| Мирная демонстрация | Wheel/+−/pan/выбор, возврат из бюджета и производства, pending блокирует фон |
| Мирный save/reload/load/reentry | Полный Match равен сохранённому, обзор100%, после повторного входа один pointermove-handler |
| Изоляция | Навигация не меняет полный Conquest/Match; один canvas, показанный canvas принадлежит проверяемой игре |
| Ошибки страницы | 0 в принятом прогоне |

Пользовательские localStorage не изменялись: тестовые слоты существовали
только в отдельном browser context, закрытом после проверки.
Временный сервер остановлен, браузер закрыт; временные инструменты
и файлы удалены.

Не проверялись физическое touch-устройство, pinch, произвольные меньшие
viewport/landscape, FPS/RAF benchmark, реальная квота localStorage
и новый оплаченный боевой E2E. Эти ограничения не выданы за приёмку
соответствующих возможностей.
