# 05 — Актуальность панелей выбранного мира

- Дата: 2026-10-26
- Пункт плана: отдельная задача Д18; [актуальная дорожная карта](../../plans/plan-2026-10-09.md), [журнал](../../plans/tasks-2026-10-09/task-status.md)
- Статус: выполнено в согласованных границах

## Цель и границы

Проверить обе кампании: данные выбранного мира после выбора на карте,
из существующего списка и мобильными стрелками, первое отображение новой
партии и загрузку. Исправлять только подтверждённые расхождения.

Мировые сведения отделены от общих данных стороны. Бюджет, исследования,
резервы, каталог проектов, журнал боёв и явно обозначенные списки всех
перелётов остаются общими. Мирной демонстрации не добавлялся список миров.
Баланс, видимость, форматы, правила загрузки и Н15–Н20 не менялись.

## Результат проверки и исправление

В проверенных сценариях население, назначения, выпуск, FIFO, работы,
разбивка колонии, корабли и группы уже читаются из свежей разрешённой
проекции и относятся к выбранному миру. Ошибок с подстановкой чисел
другого мира в этой матрице не обнаружено.

Подтверждён один дефект: **сообщение результата команды прежнего мира
оставалось после выбора другого мира** в военной кампании. Например,
после отказа оплатить заказ в домашнем мире сообщение
«Недостаточно ресурсов для полной оплаты проекта» продолжало показываться
после выбора свободного мира, где эта команда не выполнялась.
Это воспроизведено регрессиями и настоящими указательными событиями
Chromium с реальным отказом доменной операции.

В [ConquestScene](../../src/scenes/ConquestScene.ts) введён небольшой общий
`selectSystem`: сбрасывает выбор кораблей/группы, страницу и старое
сообщение, затем перерисовывает текущую проекцию. К нему подключены:

- обзорная карта;
- развёрнутое окно карты, включая mobile;
- список миров;
- мобильные стрелки;
- выбор домашней/своей системы при смене наблюдаемой стороны.

Обычная перерисовка без выбора мира сохраняет результат команды.
Доменные расчёты и корректно работавшие панели не переписывались.
Мирная демонстрация уже очищала прежнее сообщение при выборе.

### Начальный выбор

- Новая военная партия на 6/40/256 миров сразу показывает домашний мир
  blue, его население/рабочих и стартовый колонизатор, без предварительного
  клика на мир.
- Новая мирная демонстрация сразу показывает Сол и собственные данные.
- После load военная кампания сохраняет первую собственную систему
  в порядке состояния, мирная — в порядке определения карты; без колоний
  остаётся домашний ID без выдачи владения.
- В локальном режиме после load наблюдается сторона текущего хода,
  в AI-режиме — blue; red-AI остаётся paused. Старый UI-выбор не сохраняется.

## Настоящий Chromium

Headless Chromium156 через локальный CDP, настоящий Phaser/Vite,
изолированный профиль, клики через `Input.dispatchMouseEvent`,
не через вызов обработчика кнопки. Использован существующий экземпляр
игры из точного URL подключённого main-script. Браузерные проверки
выполнены отдельно от Vitest.

| Сценарий | Результат |
| --- | --- |
| Новая 40-world партия, CSS1280×720 и390×844 | Домашний мир/население показаны без выбора; реальный отказ заказа исчезает при выборе другого мира |
| Diagnostic40, обе CSS-раскладки, A→B→A через список/развёрнутую карту | Совпали выбранный ID, население, локальная очередь/готовые записи, рабочие, разбивка, HP/топливо и группа; чужие местные записи не остались |
| Diagnostic40, чистая навигация | Полное игровое состояние не изменилось |
| Diagnostic40, настоящий save→перезагрузка страницы→load | Полное состояние равно сохранённому; выбран прежний first-own; следующий реальный endTurn равен независимому доменному oracle целиком |
| Новые generated6 и256, desktop→mobile resize | Начальное население домашнего мира, выбор первого/последнего мира и мобильные стрелки прошли |
| Paid-toxic-work fixture, desktop | В работах домашнего мира нет проекта другой колонии; у цели есть оплаченный terraform0/12000; после реального endTurn показано1000/12000 |
| Diagnostic AI-red turn2, настоящий save/reload/load | blue-наблюдатель, paused; выбор мира не меняет полное состояние и не запускает AI |
| Мирная демонстрация, desktop | Начальный Сол; настоящими кликами explore/colonize Эдема; правильные заголовки/доступность панелей при выборе своей/чужой/неизвестной системы, переходы по travel/fleet/fleet-travel; чистая навигация не меняет match |
| Мирная демонстрация, save/reload/load/смена стороны | Полный match равен сохранённому; выбран Сол; закрытые сведения скрыты при смене стороны |

В браузерной диагностике40 различающиеся очереди/корабли/население
подготовлены явной подстановкой strict-valid снимка. Paid-work fixture
подготовлен чистыми командами и затем установлен в сцену; это не новый
полностью пользовательский paid E2E производства/перелёта/боя.
Мирная колонизация выполнена настоящими кликами без подстановки match.

Проверяемые ключи storage восстановлены. Временные Vite/Chromium
остановлены, изолированный временный профиль удалён.

FPS/quota или полная mobile-адаптация мирной демонстрации. Числа боевого
баланса, AI-долг и Н15–Н20 не закрываются этой проверкой.

необходимо подключать к текущему selected ID и свежей own-view,
сохраняя различие общих и местных данных. Следующая задача основной
дорожной карты — согласование Н15 по прежним предпосылкам.
