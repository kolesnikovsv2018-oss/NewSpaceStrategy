# Orion — план развития по результатам аудита

- Дата: 2026-09-07.
- Цель: связать создание проекта корабля с воспроизводимым испытанием, затем построить минимальный стратегический цикл в духе Master of Orion.
- Состояние при аудите: набор отдельных прототипов верфи, визуализации и автобоя. Переписывание с нуля и смена движка не требуются.

## Стек и исходные факты

TypeScript strict, Phaser 3, Vite 4, Yarn Classic, browser-only. Установлены Phaser 3.90.0, TypeScript 5.9.3, Vite 4.5.14. UI — Phaser Graphics/Text/Container; localStorage/JSON реализованы как неподключённая заготовка. MainScene — заглушка; экономики/галактики/исследований нет.

Исходная сборка останавливалась на 8 TS6133 в двух панелях. Проверки исполнения подтвердили одинаковые характеристики оружия всех боевых пресетов, два обновления модели за кадр, неверный учёт потерь и отказ установки части оборудования крейсера/дредноута. Производительность в FPS не измерялась.
