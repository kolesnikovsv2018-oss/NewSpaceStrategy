## Изменения и решения

### Н1 — реальная пригодность колонизатора

В [conquestAi](../../src/domain/conquestAi.ts) разделены размещённые ships
и будущие production records:

- Ship использует свой настоящий fuel, а не capacity.
- В пути учитывается ожидаемый destination. Это прогноз пригодности
  после прибытия, не присутствие/основание/службы до arrival.
- Корабль уже у потенциальной цели либо летящий к ней может дождаться
  наблюдения/survey и основания даже с fuel0. Включён случай ранее
  обнаруженного, но ещё не изученного мира.
- Для возврата на заправку нужен оплачиваемый текущим топливом leg
  до своей колонии. Только оттуда допускается quote полного бака.
- Queued/completed имеют настоящий полный стартовый бак после deploy,
  поэтому не вызывают лишний заказ.
- Исторически известный barren не объявляется колонизационной целью.
- Обездвиженный корабль, а также корабль с fuel только на небезопасный
  исходящий рейс, не блокирует законную покупку замены.

Новая регрессия полного AI-пакета проверяет ровно один новый ID/заказ,
сохранение fuel у застрявшего корабля, один endTurn и одинаковый результат
после codec round-trip. Покупка исполняется обычной командой с оплатой.

### Н2 — обратный резерв по настоящему leg

Добавлен локальный общий predicate hasReturnReserve на существующем
getTravelQuote:

1. Quote от текущего мира до выбранной цели.
2. Остаток после однократного списания исходящего fuelCost.
3. Отдельный quote от цели до любой текущей собственной колонии.
4. Проверка реальных distance/fuel/jump, без повторения исходящей длины.

При разведке из поля ранжируются только цели с допустимым обратным
резервом. Если их нет, сохраняется fallback к достижимой своей колонии.
Тот же predicate применяется к готовности колонизатора: нельзя считать
его полезным только потому, что первый leg оплачивается, если сам
планировщик не может выбрать допустимое продолжение.

Точные1131 тысячных для исходящего563 и возврата568 разрешены;
1130 и исходные1126 отклоняют опасную разведку. Проверены другой
собственный пункт возврата и невозможность обратного jump при201.
Сохранены прежние границы эвристики: старт из своей колонии и известные
однонаправленные миссии не получили нового универсального запрета.
Это не поиск многошаговых маршрутов и не оценка будущего боевого риска.

## Регрессионные тесты

Добавлен [conquestAiFuel.test.ts](../../tests/conquestAiFuel.test.ts):
18 тестов без подмены планировщика, команд, схем или route calculator.
Диагностические состояния принимаются полной conquestSchema.

- Обе стороны, fuel0/1 на barren, замена ровно одним оплачиваемым заказом.
- Колонизатор может долететь, но неизвестные цели не имеют реального
  обратного резерва: ложная пригодность не блокирует замену.
- Восстанавливаемый корабль возвращается и реально платит15/6 за полный бак.
- Incoming с fuel0: новая и ранее обнаруженная/неизученная цель.
- Queued/completed/deploy без дублирования.
- Exact return fuel и −1, более близкая другая своя колония, jump+1.
- Immutable own-view/input и полный AI-result после encode/decode.
- Опасный вылет не подменяется бесплатным fuel или скрытым ходом.

До исправления8/15 начальных проверок падали по двум исходным дефектам,
7 защитных сценариев проходили. В реализации дополнительно проверены
две incoming-границы и связанная outbound-only граница; их промежуточные
падения устранены до окончательного полного прогона.
Не повышались test deadlines ради прохождения.

## Настоящий браузер

Headless Chromium, отдельный временный профиль, реальный Phaser и
показанный single canvas; existing game получен по точному script main URL.
Проверены три диагностических strict-save, а не заявлено новое обычное
оплаченное прохождение игры:

| Сценарий | CSS | Результат |
| --- | --- | --- |
| Застрявший red colonizer |1280×720 |load paused2 → pointer Resume/confirm → AI3, ровно один новый colonizer/ID7 |
| Blue без обратного резерва |390×844 |local AI1 →2, corvette вернулся домой, а не полетел к опасной цели |
| Red incoming к ранее обнаруженной цели |390×844 |paused2 → AI3, arrival с fuel0, lastOrderId6 не вырос |

В каждом случае полный AI-state совпал с независимым доменным oracle.
Далее выполнены реальные pointer save/confirm → reload страницы →
явный load, точное равенство всего state и полного следующего результата
endTurn. На обоих CSS canvas совпал с viewport, один canvas,
минимум14px text/44px controls;0 необработанных JS exceptions.

Исходные ресурсы, исследования и расположение в сохранениях заданы
диагностической фикстурой. Сами команды/оплата/прогресс/AI и codec
настоящие; это не fake Phaser и не paid mouse E2E.
Старые полноценные paid browser-проверки Н14 относятся к отчёту19,
а не этому новому прогону. Quota/natural FPS/physical touch не измерены.

При параллельной подготовке fixture SSR сообщил о занятом HMR-порте;
SSR/export завершился, HTTP/CDP проверены отдельно. Chromium выдавал
предупреждения software WebGL/GPU; это не измерение FPS и не исправление
игрового renderer. Приёмка выше основана на фактически прошедших сценариях.

Финально MenuScene/1canvas/0storage/0ticket/0panel/0Conquest ESC handlers.
