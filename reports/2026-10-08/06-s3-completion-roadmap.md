# 06 — Сверка остатка S3 и план перехода к S4

- Дата: 2026-10-08
- Пункт плана: сверка S3 после S3.39, планирование S3.40–S3.49
- Статус: документальная задача выполнена; S3 и новые этапы остаются открытыми

## Цель и границы

Проверить навыки, незавершённые требования и неоднозначности S3; составить порядок доработок до S4. Это не реализация исследований/боевой кампании и не общий аудит проекта. Принятые S3.1–S3.39 не переоткрываются, прежние локальные изменения сохранены.

## Результат сверки

- Исследования отсутствуют в [CampaignSession](../../src/domain/campaignSession.ts); общий flight-валидатор не заменяет кампанийную проверку открытий/доступности проекта.
- Маршруты только между своими колониями. Сессия требует own ownership также для ships/fleets/production; одной отмены проверки destination недостаточно для враждебного присутствия/захвата.
- [CampaignShip](../../src/domain/campaignShips.ts) не хранит постоянное повреждение/боезапас. Топливо реализовано, широкие требования снабжения/ремонта/служб ещё не закрыты.
- [BattleScene](../../src/scenes/BattleScene.ts) запускает демонстрацию/испытание и возвращает в меню/верфь. Нет передачи стратегических участников и атомарного возврата потерь/выживших/контроля в кампанию.
- [expansion-v1](../../src/domain/campaignAiPlanner.ts) ограничен colonize/explore/endTurn. Диагностические paid red-control тесты не доказывают самостоятельное производство, проектирование или военную угрозу AI.
- S3.39 завершает совместную разведку без победителя. Мирный исход/сохранение приняты, но исходное условие победы и полный цикл S3 не реализованы.

## Изменения и решения

В [план](../2026-09-07/plan.md) добавлены таблица остатка, варианты с рекомендациями, зависимости/приёмка десяти незакрытых этапов и критерии перехода к S4:

| Этап | Объём |
| --- | --- |
| S3.40 | Только согласованный контракт оставшегося цикла |
| S3.41 | Чистая модель исследований/доступности |
| S3.42 | Исследования и кампанийный проект в UI |
| S3.43 | Оперативное состояние, эксплуатация и согласованные службы |
| S3.44 | Военные маршруты/присутствие/столкновения |
| S3.45 | Мост боя, воспроизводимость, однократное применение результата |
| S3.46 | Военная AI-policy и согласованный объём AI-конструктора |
| S3.47 | Боевой исход/завершение партии |
| S3.48 | Сквозные UI/save/версии/совместимость |
| S3.49 | Итоговая приёмка исходных требований S3 |

Рекомендации, не утверждённые правила: отдельный боевой сценарий; возможная победа захватом столицы; малое дерево исследований; кампанийная доступность поверх общего валидатора; ограниченный AI-конструктор; минимум снабжения/служб; разведка/угроза и atomic resolver с визуальным воспроизведением либо сохраняемый интерактивный encounter. Альтернативы и последствия записаны, тарифы/ID/версии/правила захвата не назначены.

Минимальная воспроизводимость/ограниченность боя нужна до применения результата в S3.45. Массовые серии/тактики/баланс/performance остаются S4. Кампанийная доступность относится к S3.41–S3.42, дальнейшие режимы редактора к S4; пересечения отмечены без двойного закрытия. Сужение служб или замена AI-конструктора шаблонами требуют отдельного согласования пользователя.

## Оставшиеся вопросы и следующий шаг

Начать с S3.40: выбрать варианты из таблицы вместе с пользователем и зафиксировать отдельный контракт с примерами/приёмкой. Планирование не означает согласие на способ победы, интерактивность боя или сокращение исходного S3. После S3.49 закрывать родительские задачи только по доказательствам либо явно утверждённому изменению объёма. Переход к S4 сейчас преждевременен.
