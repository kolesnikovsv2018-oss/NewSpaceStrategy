# 02 — Чистая модель завершения кампании

- Дата: 2026-10-08
- Пункт плана: S3.36
- Статус: выполнено в доменных границах

## Цель и границы

Реализовать [контракт S3.35](../../docs/CAMPAIGN_COMPLETION.md) отдельным чистым слоем над CampaignRun: сценарии, производный исход, авторизованные команды и запрет действий после завершения. Существующие session/run/AI API, схема кораблей, цены, зависимости, кодеки, репозиторий и сцены не изменены. Сценовый runtime остаётся S3.34/save2; новый пользовательский выбор сценария ещё отсутствует.

## Изменения и решения

- [campaignMatch.ts](../../src/domain/campaignMatch.ts): strict CampaignMatch={run,scenario}, сценарии sandbox/joint-survey-v1; constructor/query/manual/AI/takeover принимают unknown и проверяют полное состояние. Оба аргумента конструктора обязательны, без default/coerce.
- Sandbox всегда ongoing. Joint-survey-v1 completed только при знании всех шести систем обеими сторонами, без победителя, очков, даты или номера завершившего хода. Outcome возвращается отдельно, не хранится внутри match.
- Приоритет: full match → strict payload → stale → active → controller → completed → прежний run API. CAMPAIGN_COMPLETED появляется до dispatch, но не подменяет ошибки прав. Local helper обеих сторон сохранён.
- Успех повторно проверяет полный match, сохраняет scenario и отделяет receipt/summary. Ошибки не возвращают частичное состояние; прежний run API остаётся внутренним примитивом с собственными guards и безопасными сообщениями. Новый слой ничего не планирует и не обращается к IO/часам/RNG.
- Последняя ручная explore завершает сразу, без скрытого endTurn. AI принимает весь прежний атомарный пакет включая endTurn; поздний отказ откатывает и разведку. Takeover разрешён после конца, меняет только control и не возобновляет экспедицию. Нет автодохода, возврата оплаты, завершения очередей/рейсов или заправки.
- [campaignMatch.test.ts](../../tests/campaignMatch.test.ts):182 регрессии в одном файле с переиспользованием campaignAi fixtures. Прежние тесты не изменены.

Разночтений, требующих выбора нового игрового правила, не обнаружено. Контракт S3.35 сохранён. Первоначальный отказ одного диагностического теста исправлен в фикстуре: удаление transit перенесено со стоящего корабля на участника летящей группы, чтобы действительно нарушить общий маршрут.

Браузер, реальный localStorage/save/reload, физический ввод, реальная квота и профилирование не проверялись: UI/кодек/репозиторий не входят в этот шаг. Dev-server не запускался.
