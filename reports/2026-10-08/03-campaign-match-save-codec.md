## Цель и границы

Реализовать отдельный кодек3/rules1 по [контракту завершения](../../docs/CAMPAIGN_COMPLETION.md), сохраняя строгую совместимость1/2 через явную миграцию в sandbox. Не подключать новый формат к слоту или UI, не менять прежние run/session/AI API, readers/менеджеры, зависимости, цены или схемы проектов.

По запросу пользователя перед продолжением даны команды локального запуска: `yarn install --frozen-lockfile`, затем `yarn dev` из корня проекта. Агент запустил Vite, получен адрес [localhost:3000](http://localhost:3000/); сервер оставлен работающим для проверки пользователем. Текущий интерфейс остаётся S3.34/save2, без выбора сценария завершения. Запуск сервера не является браузерной приёмкой.

## Изменения и решения

- [campaignMatchSave.ts](../../src/domain/campaignMatchSave.ts): CAMPAIGN_MATCH_SAVE_SCHEMA_VERSION=3, encode/decode unknown, типизированные результаты и безопасные ошибки. Конверт строго format/schemaVersion/rulesVersion/session/control/scenario. Outcome, receipt, summary, время и UI-флаги отсутствуют.
- Encode проверяет полный match, формирует JSON, затем измеряет UTF-8. Decode: string/byte cap до parse → base strict/own session → schema → rules → обязательные и запрещённые поля версии → control/policy → scenario → полный match. Ни defaults/coerce, ни ремонта повреждённых записей.
- ID сценария:1..64 ASCII букв/цифр/дефисов; неправильная форма даёт INVALID_SAVE, неизвестный корректный ID UNSUPPORTED_SCENARIO. Ошибки control/policy раньше scenario, scenario раньше session. Недопустимый runtime match при encode даёт INVALID_STATE.
- Строгие1/2 делегированы неизменному run-reader после новых guards. Восстанавливаются только в sandbox, даже при полной общей разведке;1 добавляет local,2 сохраняет control. Нет записи, запуска AI, ретроактивного завершения или наследования сценария прошлого вызова. Явный encode создаёт3/1, старые readers и run-менеджер3 отвергают.
- Результат decode отделён от входа/других результатов. Все ShipDesign/ID/порядок/топливо/маршруты/оплаченные очереди проходят полную существующую схему. Производные исходы не сериализуются и не требуют команды при чтении.
- [campaignMatchSave.test.ts](../../tests/campaignMatchSave.test.ts):193 регрессии в одном новом файле, существующие campaignAi fixtures переиспользованы. Прежние исходники и тесты не изменены.

Разночтений с игровым контрактом не обнаружено. В первом расширенном прогоне исправлены только тестовые ожидания: подготовка фикстуры до установки spy, различие UTF-8 bytes и длины Unicode-строки. Тест чистоты восстанавливает исходные глобальные дескрипторы после проверки.
