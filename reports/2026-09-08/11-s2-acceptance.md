# 11 — Приёмочная сверка и закрытие S2

- Дата: 2026-09-08
- Пункт плана: S2 — единый проект корабля и законченный цикл испытания
- Статус: выполнено; S2 закрыт в явно уточнённых границах канонического пути, S3 не начат

## Цель и границы

Сверить четыре оставшихся родительских критерия [плана](../2026-09-07/plan.md) с текущей реализацией и проверками, подтвердить цикл проекта и определить ограниченный следующий шаг. Повторный полный аудит, изменение игрового баланса, удаление совместимого API и реализация кампании не входят в задачу.

Закрытие не означает буквального выполнения первоначальных широких формулировок об объединении всех старых моделей и стратегическом топливе. План уточнён открыто: принят единый канонический путь с отдельной legacy-совместимостью; модель топлива, AI-конструктор и исполнение служебных действий отложены. Без этих уточнений исходный пункт о топливе оставался бы невыполненным.

## Изменения и решения

Изменены только документация и проектные навыки. Исходники, тесты, зависимости, формат сохранения и формулы в этой задаче не менялись. Накопленные локальные изменения предыдущих шагов сохранены; коммит и публикация не выполнялись.

Браузерный smoke этой задачи **программный**: реальные Phaser-сцены/кнопочные события, конечные game.step в скрытой вкладке. Хранилище — временный StoragePort в памяти, а не пользовательская библиотека. Проверка «перезагрузить» в этом новом сценарии означает новый репозиторий/сцену, не перезагрузку страницы с записью localStorage. Исходный репозиторий восстановлен, браузер оставлен в меню. Проверка полного боя до результата, паузы и мышиного перекрытия диалога в этой задаче не повторялась.

Исторические доказательства отделены от новых: реальное сохранение/загрузка и испытание через UI — [S2.1](01-ship-design-trials.md); сохранение дредноута, перезагрузка страницы и тот же ID/три орудия в бою — [боевые пресеты](03-combat-presets.md); mouse-проверка блокировки фона/отмены и trial dirty/clean — [защита черновика](10-unsaved-design-guard.md). Это ранее выполненные сценарии, не новая полная E2E-сессия.

Проверены 25 Markdown-файлов, 281 относительная файловая ссылка и простой YAML-frontmatter пяти навыков (name/description); ошибок нет. Первая попытка вспомогательной проверки требовала отсутствующий js-yaml; повторная выполнена встроенными средствами Node без установки зависимостей. Проверен используемый двухполевой формат, не произвольный YAML; якоря заголовков отдельным валидатором не проверялись. Markdown-диагностика изменённых документов чистая. FPS, производительность больших флотов, кросс-браузерность и воспроизводимость баланса не измерялись.

## Оставшиеся вопросы и следующий шаг

Блокеров принятого канонического цикла по выполненной сверке не выявлено. Открытые задачи не считаются реализованными:

| Долг | Дальнейшая граница |
| --- | --- |
| mining/repair/scanner | Только определения/номинальная мощность; системы исполнения требуют отдельных правил и тестов. cargoExpansion уже пассивно увеличивает объём |
| Топливо, перелёты, экономика, исследования, AI-конструктор, сохранение кампании | Последующие задачи S3; MainScene по-прежнему заглушка |
| Удаление legacy API/универсальная миграция и полный mutable-hardening | Отдельный совместимый рефакторинг при необходимости; не скрытая часть завершённого S2. Вложенные координаты и верхние пределы HP/щита полностью не защищены |
| beforeunload, autosave/recovery, конфликты вкладок, удаление записей библиотеки | Отдельные задачи хранения/UX; нынешняя защита действует внутри верфи |
| Fixedstep/seeded RNG, дистанция смешанного оружия, тактики/friendlyFire/границы поля, баланс и большой chunk | S4 или отдельные ограниченные задачи по подтверждённой потребности; не измеренные гарантии |

**Следующий шаг — S3.1, пока только запланирован:** чистая модель небольшой фиксированной галактики, две стороны, владение/видимость систем, команды разведки/колонизации. Сначала определить предусловия этих команд; приёмка — независимые состояния партий, видимость по стороне, атомарный отказ неверных команд и локальное изменение допустимых. Тесты без Phaser и строгая типизация. UI, перелёты/топливо, экономика, исследования, AI, бой и сохранение кампании не входят в первый шаг; он не выдаётся за готовую стратегическую партию.
